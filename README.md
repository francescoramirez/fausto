# Mirra — manual de identidad

Manual corto para el dueño de una casa de perfume que vende perfumes de diseñador y perfumes árabes. Tiene el nombre, los colores, las letras, la dirección del logo y cómo hablarle al cliente.

## Cómo verlo

```bash
npm install
npm run dev -- --hostname 127.0.0.1 --port 4317
```

Abre [http://127.0.0.1:4317](http://127.0.0.1:4317).

El brief para dibujar el logo se copia en la página o se descarga en `/api/brief`.
