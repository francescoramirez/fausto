# Aromas Donofrio — manual de identidad

Manual corto para el dueño de una casa de perfume que vende perfumes de diseñador y perfumes árabes. Tiene el nombre, qué vende, cómo se ordena la tienda, los colores, las letras, cómo se escribe un producto y un mensaje, y qué no hacer.

El logo todavía no existe. Hasta que exista, la marca son las palabras Aromas Donofrio.

## Cómo verlo

```bash
npm install
npm run dev -- --hostname 127.0.0.1 --port 4317
```

Abre [http://127.0.0.1:4317](http://127.0.0.1:4317).
